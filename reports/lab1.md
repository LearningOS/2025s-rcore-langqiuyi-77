## 问答作业

### 1. 列举 SV39 页表页项的组成，描述其中的标志位作用？

SV39 页表项共有 64 位，常见标志位如下：

| 标志位          | 含义                 |
| --------------- | -------------------- |
| V（Valid）      | 表示该页表项是否有效 |
| R（Readable）   | 是否可读             |
| W（Writable）   | 是否可写             |
| X（Executable） | 是否可执行           |
| U（User）       | 是否用户态可访问     |
| G（Global）     | 跨地址空间共享       |
| A（Accessed）   | 是否被访问过         |
| D（Dirty）      | 是否被写入过         |

### 2. 缺页

缺页的常见原因：

- **Lazy 策略**：只在访问到实际页面时才分配内存。
- **Swap 策略**：内存页可能被换出，导致页表失效。

缺页时操作流程：

- 操作系统接收到 page fault 中断；
- 检查页是否应存在（如 mmap 或 swap）；
- 如果应存在，则分配物理页并更新页表项；
- 重新执行导致缺页的指令。

示例问题回答：

- **10G 连续内存对应多少页表页？**
  - 每页大小 4KB，每三级页表项覆盖范围分别为 512GB、1GB、2MB、4KB；
  - 粗略估算 10G/4K = 2.5M 个页表项，涉及多个三级页表页。

- **如何实现 Lazy 策略？**
  - 初始不分配物理页，访问时触发缺页，再实际分配。

- **页表项无效如何表示？**
  - 设置 `V=0` 表示该项无效。

---

### 3. 双页表 vs 单页表

使用双页表的原因：

- 安全隔离：用户态与内核态使用不同页表，防止权限泄露；
- 上下文切换时更快地替换页表。

相关问题回答：

- **单页表系统下如何更换页表？**
  - 切换页表基址寄存器（如 satp），刷新 TLB。

- **如何控制用户态无法访问内核页表？**
  - 设置页表项的 `U=0`，只允许内核态访问。

- **如何切换页表生效？**
  - 修改 satp 并执行 sfence.vma。

- **双页表系统下，何时需要切换？**
  - 用户态转内核态时无需切换，只有上下文切换才切换。
